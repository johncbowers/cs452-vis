# Bellman–Ford visualization

This build-free visualization follows Bellman–Ford one edge at a time. It includes:

- a graph with only positive edge weights that reaches stable shortest-path labels;
- a graph with a reachable negative cycle that is detected after `V - 1` phases;
- tense-edge, predecessor-edge, current-edge, and relaxation highlighting;
- synchronized distance and predecessor labels;
- draggable vertices, phase controls, and automatic playback.

Open `index.html` directly or serve the repository root with any static web server.
